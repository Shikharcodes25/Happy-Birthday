## 🚀 How to Deploy to GitHub Pages (Free in 2 Minutes)

1. Go to [github.com/new](https://github.com/new) and create a new **Public** repository (e.g. `happy-17th-gudiya`).
2. Click **"uploading an existing file"**.
3. Drag and drop all files from this folder (`index.html`, `style.css`, `script.js`, `.nojekyll`, `README.md`, plus your `photo.jpg` if you have one) into GitHub.
4. Click **Commit changes**.
5. In your repo, go to **Settings > Pages**.
6. Under **Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.
7. In ~60 seconds, your site will be live at:
   ```
   https://<your-username>.github.io/happy-17th-gudiya/
   ```
